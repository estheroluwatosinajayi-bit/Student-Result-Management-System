# Student Result Management System

## Project Description
This is a Python-based Student Result Management System designed to manage student records, academic scores, and class performance.

## Features
- Register new students
- View all registered students
- Search for students
- Update student details
- Delete and restore student records
- Enter scores for five subjects
- Calculate total scores, averages, and grades
- Generate individual student report cards
- Sort students by name or average
- Generate class performance reports
- Save student records using JSON files

## Technologies Used
- Python
- Visual Studio Code
- JSON

## Project Files
- main.py – Main program
- student.py – Student management
- result.py – Score and result management
- storage.py – Saving and loading records
- data/students.json – Student records
- data/deleted_students.json – Deleted student records

## How to Run
1. Install Python.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run:

   python main.py
